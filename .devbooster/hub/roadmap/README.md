# Developer Solution Roadmap

Mapa consultável de soluções para design engineering, frontend, prototipação, motion, visual development e pesquisa.

Este roadmap é escrito para leitura seletiva por LLM. Não leia todos os arquivos para resolver uma tarefa: comece por `INDEX.md`, encontre as tags/problemas relacionados e leia somente a categoria ou entrada necessária.

## Como usar

1. Identifique o problema concreto.
2. Consulte `INDEX.md` por domínio, intenção ou tag.
3. Abra apenas o arquivo da categoria indicada.
4. Compare as opções com o stack, dependências, licença e padrões do projeto.
5. Consulte a documentação oficial atual da solução antes de usar API, instalar pacote ou recomendar implementação.
6. Nunca trate uma entrada como ordem de uso ou como “melhor ferramenta” universal.

## Escopo

O roadmap reúne soluções e referências do catálogo curado em:

- https://designengineer.tools/

Ferramentas de IDE, agentes de código e navegadores ficam fora do mapa principal por serem preferências de ambiente. O roadmap não impõe Cursor, Codex, Claude, Arc, Chrome, Firefox ou qualquer ferramenta equivalente.

## Formato das entradas

Cada entrada usa, quando aplicável:

- **Resolve:** problema que a solução atende.
- **Resumo:** o que é e por que pode ser útil.
- **URL:** página oficial ou fonte primária.
- **Tags:** termos para recuperação seletiva.
- **Verificar antes de usar:** versão, API, compatibilidade, licença, custo ou limitações relevantes.

A curadoria local é um ponto de partida. A documentação oficial atual é a autoridade sobre comportamento e API.

# Gradients

## Local guidance

- Use gradients to establish depth, focus, atmosphere, or hierarchy—not to decorate every surface.
- Check text and control contrast over the full gradient area, including interpolation edges.
- Keep gradient definitions in tokens or named utility classes when reused.
- Avoid large animated gradients unless their rendering cost and reduced-motion behavior are understood.
- Test the gradient in the actual color space and browser targets used by the project.

## Official verification

For easing-gradient exploration, consult:

- https://larswander.com/writing/easing-gradients/
- the current CSS gradient/color documentation for the project's supported browsers.

The article is a design reference, not a substitute for current browser compatibility verification.

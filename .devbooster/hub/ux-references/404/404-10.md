# Reference — 404 paired with dashboard preview

- image: 404-10.png
- type: 404 error page for a SaaS product
- source: vision description (image not stored)

## Overview

An error message and actions appear on the left, while a partial product dashboard preview appears on the right, suggesting the home destination without becoming route content.

## Route Layout Blueprint

The left column contains an error label, a two-line title, an availability explanation, and two buttons. The right side contains a large application-like window with internal navigation, metric cards, a chart, and a table, partially cropped.

## Sections (top → bottom)

- message: error label, title, and explanation.
- actions: back and home.
- visual preview: elevated dashboard mockup with internal areas used only as illustration.

## Components

- label, heading, and paragraph: 1 each.
- buttons: 2.
- product mockup: 1 decorative panel containing a sidebar, cards, chart, and table.

## Density and Rhythm

Balanced, with a clean text area and a dense, detailed visual preview.

## Observed States

Error/unavailable state; the preview does not represent functional route content.

## Observed Interaction Patterns on the Route

Only the recovery buttons appear interactive; the preview should be treated as decoration.

## Observed Style (qualitative)

SaaS, corporate, and product-oriented.

## Ideal For

B2B applications and dashboards that want to reinforce the product visually during error states.

## Do Not Reproduce

Product name, data, avatars, copy, and the specific mockup interface.

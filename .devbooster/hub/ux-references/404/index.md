# Páginas 404

Referências visuais para páginas de erro 404 — páginas que o usuário encontra ao tentar acessar uma rota inexistente.

Use esta categoria para explorar:

- Estrutura e tom da página de erro
- Combinação de mensagem, ilustração e ação
- Chamada para recuperação (voltar, buscar, home)
- Estilos: simples, ilustrado, dividido, com busca, com navegação

## Referências

### [404-01](404-01.md) — 404 minimalista à esquerda

- **Tipo:** 404 error page
- **Tags:** `minimal` `clean` `editorial` `left-aligned` `spacious`
- **Componentes:** rótulo de erro, título, texto de apoio, 2 botões (voltar/home)
- **Resumo:** coluna estreita à esquerda com muito espaço vazio. Ideal para sites institucionais, SaaS e apps com recuperação simples.

### [404-02](404-02.md) — 404 centralizado com atalhos de ajuda

- **Tipo:** 404 error page com navegação de recuperação
- **Tags:** `centered` `clean` `corporate` `help-links`
- **Componentes:** indicador 404, título + mensagem, ações, cards de ajuda
- **Resumo:** bloco superior com mensagem e respiro, seguido de grid de recursos. Ideal para SaaS, documentação e produtos com central de ajuda.

### [404-03](404-03.md) — 404 centralizado com fundo em grid

- **Tipo:** 404 error page
- **Tags:** `centered` `minimal` `geometric` `technical`
- **Componentes:** ícone contextual, título, descrição, ações
- **Resumo:** composição vertical curta e centralizada sobre fundo com grade geométrica. Ideal para ferramentas digitais, dashboards e produtos com linguagem de grid.

### [404-04](404-04.md) — 404 com busca e ilustração geométrica

- **Tipo:** 404 error page com busca local
- **Tags:** `search` `editorial` `geometric` `illustrated` `asymmetric`
- **Componentes:** rótulo de erro, título + texto, formulário de busca, ilustração
- **Resumo:** equilíbrio entre texto funcional e mídia visual, com busca integrada. Ideal para sites de conteúdo, bibliotecas digitais e páginas de erro com descoberta.

### [404-05](404-05.md) — 404 com lista de recursos centralizada

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `404-XX.png` ou `404-XX.webp` (exemplo: `404-01.png`). Após salvar, atualize o mapa de tags e o catálogo de referências deste `index.md` (formato no `VISION_PROMPT.md`).

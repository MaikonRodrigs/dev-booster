# Reference — Sales and orders dashboard

- image: dashboard-03.png
- type: commerce analytics dashboard
- source: vision description (image not stored)

## Overview

A commerce dashboard for reviewing sales performance and recent orders.

## Route layout blueprint

A personalized dashboard header and period controls precede three compact metric cards. A large sales trend chart follows, then an orders section with status tabs and a detailed order table.

## Sections (top to bottom)

- Dashboard header: greeting, date range, and period controls.
- Summary metrics: sales, orders, and average order value cards.
- Sales report: one wide line/area chart with local period tabs.
- Orders report: table with status tabs, customer details, amounts, and pagination.

## Components

- Metric cards: three.
- Trend chart: one wide sales chart.
- Order table: multiple rows with status, date, amount, and customer.
- Tabs and controls: period selector, order-status tabs, row menus, and pagination.

## Density and rhythm

Dense but orderly, moving from high-level metrics to detailed records.

## Observed states

Populated sales and paid-order data; no loading, error, or empty state is visible.

## Observed route interactions

Period controls, chart range, order tabs, row selection, row menus, and pagination.

## Observed style (qualitative)

Polished operational commerce dashboard.

## Ideal for

Online stores, marketplaces, and subscription commerce teams.

## Do not reproduce

Ignore global shell, user identities, exact amounts, customer data, logos, and proprietary text.

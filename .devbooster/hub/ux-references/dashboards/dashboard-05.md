# Reference — Active users and traffic dashboard

- image: dashboard-05.png
- type: user activity analytics dashboard
- source: vision description (image not stored)

## Overview

A dashboard for monitoring site traffic trends and recently active users.

## Route layout blueprint

A greeting and supporting description precede a large bar chart with comparison line. Below, a recently-active section contains filter-builder controls, search, bulk-selection state, and a user table.

## Sections (top to bottom)

- Intro and controls: title, description, period tabs, date range, and filters.
- Traffic chart: one wide bar chart with an overlaid comparison trend.
- Active-user table: filter controls, selected-row state, access badges, activity dates, and pagination.

## Components

- Traffic chart: one monthly bar chart.
- Filter builder: field selector, operator selector, value input, and clear action.
- User table: multiple rows with avatars, email, access tags, and dates.

## Density and rhythm

Analytical and moderately dense, with the table carrying most interaction complexity.

## Observed states

Populated chart and table with several selected rows; no loading or error state.

## Observed route interactions

Period controls, date range, filters, search, row selection, clear-all, menus, and pagination.

## Observed style (qualitative)

Operational, data-heavy dashboard.

## Ideal for

Admin analytics, user engagement, and access-monitoring products.

## Do not reproduce

Ignore global shell, promotional widgets, identities, exact data, names, emails, avatars, logos, and proprietary wording.

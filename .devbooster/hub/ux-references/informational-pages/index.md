# Páginas informativas

Referências visuais para páginas de conteúdo institucional e informativo — sobre nós, termos, privacidade, ajuda e documentação.

Use esta categoria para explorar:
- Layout de página de conteúdo longo
- Tipografia e hierarquia textual
- Seções de informação organizada
- Integração com navegação e índice
- Tom: profissional, confiável, claro

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `info-XX.png` ou `info-XX.webp` (exemplo: `info-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `landing-pages` — páginas de marketing
- `contact` — páginas de contato
- `pricing` — páginas de preços

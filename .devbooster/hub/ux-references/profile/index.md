# Páginas de perfil

Referências visuais para páginas de perfil de usuário — informações pessoais, avatar, bio, atividades e preferências.

Use esta categoria para explorar:
- Layout de perfil com foto e informações
- Abas de atividade, configurações ou histórico
- Edição de dados pessoais
- Perfil público vs. perfil privado
- Estilo: social, profissional, plataforma

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `profile-XX.png` ou `profile-XX.webp` (exemplo: `profile-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `settings` — configurações de conta
- `dashboards` — dashboards com visão do usuário

## Overview

A profile-editing route that lets a user update identity information, public availability, profile links, and biography. The page combines a branded profile header with grouped editable cards and persistent save controls.

## Route layout blueprint

A wide cover banner and overlapping avatar establish the profile context. The identity row places the user identity on the left and share/view actions on the right. Below, a personal-information card contains name, email, and avatar upload controls. A second profile card begins with an availability toggle and continues with username, website, and description fields; additional settings continue below the viewport.

## Sections (top to bottom)

- Profile header: wide decorative cover, overlapping avatar, identity text, and share/view actions.
- Personal info card: section label and helper text beside a card containing first name, last name, email, current avatar, upload drop zone, and cancel/save actions.
- Profile card: availability toggle, username field, website field, and multi-line description editor with character counter.
- Continuing profile fields: the next field begins below the visible viewport, indicating a longer form.

## Components

- Cover and identity header: one cover, one avatar, display name, handle, and two actions.
- Personal info form: two name inputs, one email input, one avatar preview, and one upload area.
- Availability control: one toggle with explanatory supporting text.
- Profile link fields: one username input with a fixed prefix and one website input with a protocol prefix.
- Description editor: one multi-line text area with required indicator, helper icon, and character counter.
- Form actions: one cancel button and one emphasized save-changes button inside the personal card.

## Density and rhythm

Balanced and moderately spacious. The header is visually dominant, while the form cards use compact control rows with clear boundaries and generous separation between major sections.

## Observed states

The route is in an editable, populated state. Availability is enabled, an avatar is present, and no validation errors, loading indicators, empty states, or upload progress are visible.

## Observed route interactions

Share, view profile, text inputs, avatar upload, availability toggle, link editing, description formatting or text entry, cancel, and save changes are implied local interactions.

## Observed style (qualitative)

Polished, profile-centric, and form-oriented, combining a public-facing hero with focused editable cards.

## Ideal for

Creator profile editors, professional networking settings, freelancer platforms, portfolio builders, and personal-brand management tools.

## Do not reproduce

Do not reproduce logos, product names, personal names, handles, proprietary text, portraits, cover artwork, or exact URLs. Use generic identity data and abstract visual assets.

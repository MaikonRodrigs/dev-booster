# Reference — Personal details settings form

- image: settings-01.png
- type: settings profile form
- source: vision description (image not stored)

## Overview

A personal-account settings screen for updating identity, contact details, profile media, location, biography, and portfolio files.

## Route layout blueprint

A route title and internal tab bar sit at the top. Below, a two-column form uses descriptive labels on the left and controls on the right, followed by personal fields, avatar upload, location selectors, a rich-text biography editor, and portfolio uploads.

## Sections (top to bottom)

- personal information: name, email, profile-photo upload, role, country, and timezone.
- biography: rich-text editor with formatting toolbar and character counter.
- portfolio projects: upload dropzone and one completed file row with progress.

## Components

- internal tabs, labeled form rows, text fields, dropdowns, upload controls, rich-text editor, file row, cancel, and save actions.

## Density and rhythm

Balanced and form-dense, with generous horizontal alignment and divider-separated rows.

## Observed states

Populated edit state; profile media exists and the visible file upload is complete.

## Observed route interactions

Internal tabs, fields, dropdowns, uploads, editor formatting, file deletion, cancel, and save.

## Observed style (qualitative)

Clean, restrained, and administrative.

## Ideal for

Account settings, creator profiles, and workspace member administration.

## Do not reproduce

Omit global chrome, product identity, names, emails, portraits, logos, proprietary text, and specific uploaded files.

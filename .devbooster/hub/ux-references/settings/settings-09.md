# Reference — Team members by role

- image: settings-09.png
- type: team members administration page
- source: vision description (image not stored)

## Overview

A role-oriented team directory separating administrators from regular account users and showing membership activity metadata.

## Route layout blueprint

Breadcrumbs and a route title lead to an add-member action. Two vertically stacked sections pair explanatory copy with bordered tables.

## Sections (top to bottom)

- admin users: five-row table with selection, identity, date added, last active, and row actions.
- account users: second five-row table with the same structure.

## Components

Two role sections, two tables, checkbox headers, identity metadata, activity columns, delete/edit actions, and add-member button.

## Density and rhythm

Information-dense but orderly, with repeated table patterns.

## Observed states

Populated directory with dates and activity metadata.

## Observed route interactions

Breadcrumb, add member, bulk selection, delete, and edit.

## Observed style (qualitative)

Structured and utilitarian.

## Ideal for

Role-based access management and compliance-oriented admin panels.

## Do not reproduce

Omit real names, portraits, emails, dates, and proprietary labels.

# Páginas de login

Referências visuais para páginas de autenticação — login com email, redes sociais, layout dividido e outras variações.

Use esta categoria para explorar:
- Formulário de login e campos
- Opções de autenticação social
- Layout dividido com imagem ou mockup
- Card centralizado vs. tela cheia
- Links para cadastro e recuperação de senha

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `login-XX.png` ou `login-XX.webp` (exemplo: `login-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `sign-up` — páginas de cadastro
- `forgot-password` — recuperação de senha
- `verification` — verificação de conta

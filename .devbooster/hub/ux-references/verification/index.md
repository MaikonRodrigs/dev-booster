# Páginas de verificação

Referências visuais para páginas de verificação de conta — confirmação de email, código de verificação, validação de identidade.

Use esta categoria para explorar:
- Layout de verificação por código
- Estados: enviado, expirado, reenviar
- Confirmação de email ou SMS
- Transição entre cadastro e verificação
- Feedback visual de código correto/incorreto

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `verify-XX.png` ou `verify-XX.webp` (exemplo: `verify-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `sign-up` — páginas de cadastro
- `sign-in` — páginas de login
- `forgot-password` — recuperação de senha

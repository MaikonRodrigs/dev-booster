# Developer Communication Utilities

## Ray.so

Use https://ray.so/ for readable code images when communicating an implementation or review. Prefer plain code blocks for searchable documentation and issue tracking. Verify current export/privacy behavior on the official site before using it with sensitive code.

## RegExr

Use https://regexr.com/ for exploration and explanation, not as proof that a pattern works in the target runtime. Validate flags, Unicode behavior, escaping, catastrophic backtracking risk, and tests in the project's actual language/runtime.

## Local rule

External utilities must not become hidden dependencies of the product. Document the reproducible result—the token, SVG, regex, or decision—not merely the tool used to create it.

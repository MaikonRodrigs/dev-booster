# Reference — Form beside an interactive map

- image: contact-08.png
- type: contact form with location map
- source: vision description (image not stored)

## Overview

A practical contact route that places an inquiry form beside a large map centered on one office location. A location directory continues below the main two-column block.

## Route layout blueprint

The main route area is a two-column split: a left form column and a right dark map panel. The form contains heading, description, name row, email, phone, message, consent, and submit action. Below, a locations section presents an introduction on the left and office entries in multiple columns.

## Sections (top to bottom)

- Inquiry block: left-aligned title and supporting copy above a stacked form.
- Map block: one large map panel with a single highlighted office marker and a visible city label.
- Locations directory: left introduction plus a multi-column list of offices, with additional entries continuing below the visible area.

## Components

- Contact form: two name inputs, email, phone selector/input, message textarea, consent checkbox, and submit button.
- Map: one large interactive-looking map with one location marker.
- Directory: multiple office entries with city names and address lines.

## Density and rhythm

Efficient and moderately dense in the form area, with the map acting as a strong visual counterweight. The directory below is structured for scanning.

## Observed states

Empty form, populated location directory, and a visible map with one marker. No validation, loading, error, or success state is displayed.

## Observed route interactions

Form controls, consent, submit action, map panning/zooming, and office entries appear potentially interactive.

## Observed style (qualitative)

Functional, modern, and location-oriented, combining a conventional form with a strong geographic utility element.

## Ideal for

Businesses with a primary office, service area, showroom, or local customer-support presence.

## Do not reproduce

Ignore global navigation. Do not reproduce map provider details, exact city/address data, proprietary text, product identity, logos, or specific map styling.

# Páginas de contato

Referências visuais para páginas de contato e suporte — formulários, canais de atendimento, informações da empresa e help centers.

Use esta categoria para explorar:
- Layout de formulário de contato
- Organização de canais (email, chat, telefone)
- Páginas de help center ou FAQ
- Seções de escritório ou localização
- Tom da comunicação: formal, acolhedor, direto

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `contact-XX.png` ou `contact-XX.webp` (exemplo: `contact-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `informational-pages` — páginas institucionais
- `footer` — rodapés

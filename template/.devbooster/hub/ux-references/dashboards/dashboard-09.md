# Reference — Vendor monitoring dashboard

- image: dashboard-09.png
- type: vendor monitoring dashboard
- source: vision description (image not stored)

## Overview

A monitoring route combining a stacked monthly rating chart, usage capacity, and a vendor management table.

## Route layout blueprint

A welcome header and customize/export controls precede a large chart card paired with a compact usage gauge card. Below is a vendor table with view tabs, import/add actions, search, filters, tags, and pagination.

## Sections (top to bottom)

- Header: title and local actions.
- Monitoring overview: stacked bar chart and capacity gauge card.
- Vendor movements: tabbed table with controls and vendor rows.

## Components

- Stacked bar chart: one monthly vendor-rating chart.
- Gauge: one capacity/usage visualization.
- Vendor table: multiple rows with ratings, change badges, dates, categories, and actions.
- Tabs and controls: view tabs, import, add, search, filters, and pagination.

## Density and rhythm

Dense operational layout with strong separation between monitoring and records.

## Observed states

Populated monitoring data and table; a near-limit usage state is visible, but no loading or error state.

## Observed route interactions

Customize, export, view report, upgrade/local capacity action, tabs, import, add, search, filters, row actions, and pagination.

## Observed style (qualitative)

Enterprise monitoring and compliance interface.

## Ideal for

Vendor oversight, infrastructure monitoring, and security operations.

## Do not reproduce

Ignore global shell, upgrade messaging, names, logos, exact values, proprietary text, and vendor data.

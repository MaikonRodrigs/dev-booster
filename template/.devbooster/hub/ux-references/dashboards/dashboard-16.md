# Reference — Balance and transaction dashboard

- image: dashboard-16.png
- type: personal finance dashboard
- source: vision description (image not stored)

## Overview

A finance overview that combines total balance performance, savings/category cards, and a recent-transactions table with a persistent card summary.

## Route layout blueprint

A large balance chart occupies the top of the main content. Three horizontal summary cards follow. A full-width recent-transactions table sits beneath, while a right-side panel contains card details and a compact balance chart.

## Sections (top to bottom)

- Balance overview: total balance metric and line chart.
- Financial goals: three summary cards with progress bars.
- Recent transactions: tabbed, searchable table with download/report actions.
- Card summary panel: payment cards, tabs, balances, and a mini bar chart.

## Components

- Main chart: one balance trend chart.
- Summary cards: three goal/savings cards.
- Transaction table: multiple rows with merchant, amount, date, category, account, and edit action.
- Side panel: card carousel, internal tabs, values, and mini chart.

## Density and rhythm

Highly structured and moderately dense, with the transaction table as the main operational area.

## Observed states

Populated balance, goals, cards, and transactions; no loading, error, or empty state.

## Observed route interactions

Sync, messages, report, card tabs, period controls, transaction filters/tabs, search, downloads, and row edits.

## Observed style (qualitative)

Polished personal-finance command center.

## Ideal for

Banking, financial planning, savings, and expense-management apps.

## Do not reproduce

Ignore global shell, names, card data, exact values, payment brands, logos, and proprietary text.

# Reference — Profile engagement dashboard with messaging

- image: dashboard-19.png
- type: profile analytics and collaboration dashboard
- source: vision description (image not stored)

## Overview

A profile-performance route showing profile views, ranked fan/designer lists, and an adjacent conversation panel.

## Route layout blueprint

The main route contains a large profile-views line chart followed by two side-by-side ranked lists. A narrow contextual messaging panel remains alongside the route content and is treated as an auxiliary panel rather than core dashboard content.

## Sections (top to bottom)

- Profile analytics: title, period controls, and one large line chart.
- Ranked lists: two columns for top fans and favorite designers, each with rows, likes, edit affordances, and view-all actions.
- Auxiliary context: possible global or auxiliary chat panel — ignored in the route blueprint.

## Components

- Line chart: one high-variance profile-view trend.
- Ranked lists: two lists with approximately seven visible entries each.
- List rows: avatar, person label, handle, like count, and edit action.
- View-all actions: one per list.

## Density and rhythm

Balanced and spacious, with the chart providing the main visual focus and the lists creating a scannable lower grid.

## Observed states

Populated chart and ranked data; active conversation content is visible in the auxiliary panel, but no dashboard loading/error state appears.

## Observed route interactions

Period controls, edit actions, view-all links, and chart menus. Messaging controls belong to the auxiliary panel and are ignored.

## Observed style (qualitative)

Social analytics dashboard with collaborative context.

## Ideal for

Creator profiles, community products, professional networks, and portfolio platforms.

## Do not reproduce

Do not reproduce the auxiliary chat panel, names, avatars, exact messages, profile data, logos, or proprietary text.

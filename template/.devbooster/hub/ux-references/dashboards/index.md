# Dashboards

Referências visuais para páginas de dashboard — telas de métricas, análise, administração e visão geral de sistemas.

Use esta categoria para explorar:

- Organização de métricas e cards
- Disposição de gráficos e tabelas
- Navegação lateral ou superior
- Filtros, períodos e ações rápidas
- Tipos: analytics, financeiro, vendas, customer, ecommerce, banking, fintech

## Referências

### [dashboard-01](dashboard-01.md) — Dashboard de conteúdo e membros

- **Tipo:** membership analytics dashboard
- **Tags:** `analytics` `membership` `editorial` `clean`
- **Componentes:** gráfico de linha, cards de métrica, action cards, cards de post, lista de membros
- **Resumo:** receita recorrente, crescimento de membros, engajamento e conteúdo; cabeçalho espaçoso e módulos compactos. Ideal para plataformas de membros, creators, newsletters e conteúdo.

### [dashboard-02](dashboard-02.md) — Tabela de analytics de tráfego do site

- **Tipo:** web analytics dashboard
- **Tags:** `analytics` `web` `table-heavy` `corporate`
- **Componentes:** cards de métrica, tabs, tabela de dados, controles
- **Resumo:** cards compactos seguidos de tabela altamente estruturada. Ideal para product analytics, web analytics e relatórios de performance.

### [dashboard-03](dashboard-03.md) — Dashboard de vendas e pedidos

- **Tipo:** commerce analytics dashboard

- **Resumo:** métricas de alto nível com transição para registros detalhados. Ideal para lojas online, marketplaces e comércio por assinatura.

## Como adicionar referências

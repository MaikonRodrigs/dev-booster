# Seções de funcionalidades

Referências visuais para seções de funcionalidades comuns em landing pages e sites institucionais — destaques de produto, cards de recurso, grids de funcionalidades.

Use esta categoria para explorar:
- Grids e listas de funcionalidades
- Cards com ícone, título e descrição
- Layouts alternados com imagem e texto
- Seções de comparação ou diferenciais
- Hierarquia visual de recursos

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `feature-XX.png` ou `feature-XX.webp` (exemplo: `feature-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `landing-pages` — páginas completas de marketing
- `header-sections` — seções de cabeçalho e hero
- `pricing` — seções de preços

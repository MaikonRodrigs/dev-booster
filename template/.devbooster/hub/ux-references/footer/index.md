# Footers

Referências visuais para rodapés de páginas — links, informações institucionais, newsletter, redes sociais e chamadas finais.

Use esta categoria para explorar:
- Estrutura e densidade do rodapé
- Organização de links e colunas
- Presença de newsletter, redes sociais ou selos
- Rodapés simples vs. rodapés completos (sitemap)
- Tom: institucional, direto, criativo

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `footer-XX.png` ou `footer-XX.webp` (exemplo: `footer-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `header-sections` — seções de cabeçalho
- `feature-sections` — seções de funcionalidades

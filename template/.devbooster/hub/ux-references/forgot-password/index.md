# Recuperação de senha

Referências visuais para páginas de recuperação de senha — fluxo de "esqueci minha senha", redefinição e confirmação.

Use esta categoria para explorar:
- Layout do formulário de recuperação
- Instruções e feedback de envio
- Fluxo de redefinição de senha
- Tom: acolhedor, direto, seguro
- Integração com login

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `forgot-XX.png` ou `forgot-XX.webp` (exemplo: `forgot-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `sign-in` — páginas de login
- `sign-up` — páginas de cadastro
- `verification` — páginas de verificação

# Seções de cabeçalho

Referências visuais para cabeçalhos de página e seções hero — abertura de landing pages, introduções de produto e navegação principal.

Use esta categoria para explorar:
- Hero com título, subtítulo e CTA
- Navegação superior e menus
- Layouts de cabeçalho: centralizado, dividido, com imagem ou vídeo
- Hero com mockup de produto ou dashboard
- Chamada para ação principal

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `header-XX.png` ou `header-XX.webp` (exemplo: `header-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `landing-pages` — páginas completas de marketing
- `feature-sections` — seções de funcionalidades
- `footer` — rodapés

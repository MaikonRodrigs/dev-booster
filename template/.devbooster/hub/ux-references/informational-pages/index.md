# Páginas informativas

Referências visuais para páginas informativas e operacionais de aplicações — tabelas, calendários, mensagens, projetos, editores, resultados de busca e perfis em workspaces de back-office.

Use esta categoria para explorar:

- Workspaces densos com tabelas, toolbars e painéis laterais
- Calendários (mês, semana, dia)
- Mensagens e conversas de projeto
- Editores de conteúdo (CMS)
- Resultados de busca com mapa e diretórios
- Estilo comum: clean, estruturado, enterprise-style

## Referências

### [informational-01](informational-01.md) — Tabela de histórico de trades

- **Tipo:** trade history workspace
- **Tags:** `trades` `table` `back-office` `structured`
- **Componentes:** tabela de transações, badges de status, ações de linha
- **Resumo:** workspace denso em faixas horizontais claras com tabelas e toolbars. Ideal para back-offices SaaS, gestão de projetos, CRM, dev platforms e marketplaces.

### [informational-02](informational-02.md) — Tabela compacta de histórico de trades

- **Tipo:** transaction management page
- **Tags:** `trades` `table` `back-office` `compact`
- **Componentes:** tabela larga com ~8 linhas visíveis, badges de status, links de edição inline
- **Resumo:** versão compacta do workspace de transações. Ideal para gestão de transações e admin de plataformas.

### [informational-03](informational-03.md) — Arquivos de projeto e biblioteca de assets

- **Tipo:** project asset management page
- **Tags:** `assets` `library` `files` `back-office`
- **Componentes:** dropzone de upload, três cards de arquivo enviado, tabela de anexos com indicadores de tipo
- **Resumo:** biblioteca de arquivos com upload e metadados. Ideal para gestão de projetos, CMS e plataformas com acervo.

### [informational-04](informational-04.md) — Tabela de pedidos e faturas

- **Tipo:** order management page
- **Tags:** `orders` `billing` `table` `back-office`
- **Componentes:** toolbar de filtros, tabela com ~7 linhas e 5 grupos de dados, estados de pagamento (pago/reembolsado/cancelado)
- **Resumo:** gestão de pedidos com tabela estruturada. Ideal para ecommerce, marketplaces e back-offices de operação.

### [informational-05](informational-05.md) — Pedidos de assinatura e histórico de billing

- **Tipo:** orders and billing page
- **Tags:** `orders` `billing` `subscriptions` `back-office`
- **Componentes:** tabela principal de pedidos (~10 linhas), tabela secundária de faturas, controles de busca por seção
- **Resumo:** histórico de assinaturas e cobranças em tabela densa. Ideal para assinaturas e operações de billing.

### [informational-06](informational-06.md) — Dashboard de visão geral de clientes

- **Tipo:** customer analytics and management page
- **Tags:** `customer` `analytics` `back-office`
- **Componentes:** três cards de métrica, tabela com ~7 linhas de empresas, avatar clusters e indicador de uso horizontal
- **Resumo:** métricas + gestão em um workspace. Ideal para CRM, customer success e portais de admin.

### [informational-07](informational-07.md) — Lista de clientes com filtros de data

- **Tipo:** customer management table
- **Tags:** `customer` `table` `filters` `back-office`
- **Componentes:** três cards de resumo, tabela com ~7 linhas, affordances de editar/deletar por linha
- **Resumo:** tabela de clientes com filtros. Ideal para bancos de dados de clientes e operações de conta.

### [informational-08](informational-08.md) — Visão mensal de calendário

- **Tipo:** calendar month workspace
- **Tags:** `calendar` `month` `back-office`
- **Componentes:** grid de sete colunas, eventos esparsos nas primeiras semanas e clusters densos perto da data selecionada, chips de evento por categoria
- **Resumo:** grade mensal com toolbars de navegação. Ideal para agendamento e produtos de calendário.

### [informational-09](informational-09.md) — Agenda semanal de calendário

- **Tipo:** calendar week view
- **Tags:** `calendar` `week` `back-office`
- **Componentes:** grid de tempo de sete colunas, rótulos de hora à esquerda, blocos de evento coloridos por dia/hora
- **Resumo:** visualização semanal com colunas de dias. Ideal para agendamento e times.

### [informational-10](informational-10.md) — Calendário diário com detalhes de evento

- **Tipo:** calendar day view with details
- **Tags:** `calendar` `day` `back-office`
- **Componentes:** timeline principal do dia, navegador mensal compacto, painel de detalhes do evento com avatares de convidados e ações
- **Resumo:** visão diária com painel de detalhes. Ideal para agendamento e gestão de rotina.

### [informational-11](informational-11.md) — Caixa de entrada e conversa

- **Tipo:** messaging workspace
- **Tags:** `messaging` `inbox` `back-office`

### [informational-12](informational-12.md) — Conversa de projeto com painel de perfil

- **Componentes:** coluna de conversa principal, coluna estreita de perfil, entradas de experiência e ações de perfil
- **Resumo:** conversa de projeto com painel de contexto. Ideal para gestão de projetos e colaboração.

### [informational-13](informational-13.md) — Visão geral de projeto com feed de atividade

### [informational-14](informational-14.md) — Visão geral de projeto com sidebar de mensagens

- **Tipo:** project detail page with messaging
- **Tags:** `project` `messaging` `back-office`

- **Resumo:** detalhe de projeto com mensagens integradas. Ideal para plataformas de colaboração e gestão.

### [informational-15](informational-15.md) — Inspetor de eventos de fonte de dados

- **Tipo:** developer data source page
- **Tags:** `developer` `data-source` `inspector` `back-office`
- **Componentes:** duas colunas (lista de eventos estreita + inspetor largo), tabela de eventos paginada, viewer de código/schema com tabs
- **Resumo:** inspetor técnico com painéis de detalhe. Ideal para dev platforms, observabilidade e integrações.

### [informational-16](informational-16.md) — Resultados de busca de imóveis com mapa

- **Tipo:** property search results page
- **Tags:** `search-results` `map` `listings` `back-office`
- **Componentes:** coluna de resultados + coluna de mapa, quatro cards de imóvel (imagem, metadados, rating, preço, favorito)
- **Resumo:** lista de resultados com mapa e filtros. Ideal para marketplaces, classificados e busca com mapa.

### [informational-17](informational-17.md) — Perfil profissional com portfólio

- **Tipo:** designer profile page
- **Tags:** `profile` `portfolio` `back-office`
- **Componentes:** cover largo + avatar sobreposto, quatro cards de experiência em grid 2 colunas, galeria de projetos categorizada
- **Resumo:** perfil com portfólio e histórico. Ideal para diretórios de talentos, creators e redes profissionais.

### [informational-18](informational-18.md) — Perfil de designer e experiências

- **Tipo:** designer directory profile
- **Tags:** `profile` `portfolio` `directory` `back-office`
- **Componentes:** cover + avatar sobreposto, três cards de experiência, quatro tabs de categoria de projeto + thumbnails
- **Resumo:** perfil de diretório com experiências. Ideal para diretórios de designers e talent marketplaces.

### [informational-19](informational-19.md) — Editor de conteúdo rich text

- **Tipo:** CMS article editor
- **Tags:** `editor` `cms` `content` `back-office`
- **Componentes:** coluna grande de editor + sidebar estreita de autor, toolbar rich-text (tipografia, formatação, alinhamento, listas, links, imagens), entradas de trabalhos relacionados
- **Resumo:** editor de artigos com toolbars e painéis de publicação. Ideal para CMS, blogs e produtos de conteúdo.

### [informational-20](informational-20.md) — Estado de não encontrado (404)

- **Tipo:** 404 error page
- **Tags:** `404` `error` `state`
- **Componentes:** heading de status, mensagem de apoio (sem formulário, ilustração ou ação visível)
- **Resumo:** estado de erro no contexto enterprise/back-office. Consulte também a categoria `404` para páginas de erro dedicadas.

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `informational-XX.png` ou `informational-XX.webp` (exemplo: `informational-01.png`). Após salvar, atualize o mapa de tags e o catálogo de referências deste `index.md` (formato no `VISION_PROMPT.md`).

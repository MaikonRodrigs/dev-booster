## Overview

A content-management route for editing a long-form article excerpt while keeping author information and related works visible.

## Route layout blueprint

The main route preserves the described operational content while treating sidebars, global navigation, account cards, promotional widgets, and persistent shell controls as global or auxiliary chrome.

## Sections (top to bottom)

- Content header: breadcrumb, title, author/date line, save-draft action, and publish action.
- Editor: featured-excerpt label, formatting toolbar, and large rich-text editing surface.
- Author sidebar: cover image, avatar, identity, metrics, links, biography, tags, and notable works list.

## Components

- One large editor column and one narrow author sidebar.
- One rich-text toolbar with typography, formatting, alignment, list, link, image, and enhancement controls.
- Multiple related-work entries.

## Density and rhythm

The route is information-dense but organized into clear horizontal bands, cards, tables, or panels. Spacing supports scanning of controls and repeated data rows without making the workspace feel sparse.

## Observed states

The route is populated with representative data. Visible states include selected tabs, active filters or views, status badges, pagination, and—in relevant screens—attachments, online presence, event detail, upload progress, or an empty not-found state. No unobserved loading or error behavior is inferred.

## Observed route interactions

Visible local interactions include tabs, search, filters, date or view selectors, sorting, pagination, upload, import/export, add actions, edit/delete controls, row selection, profile actions, calendar navigation, message composition, and content-editor commands where present. Global navigation and shell controls are ignored.

## Observed style (qualitative)

Clean, structured, enterprise-style application UI with strong emphasis on tables, toolbars, repeatable rows, and contextual side panels.

## Ideal for

SaaS back offices, project-management tools, CRM systems, developer platforms, scheduling products, marketplaces, collaboration suites, CMS tools, and profile directories.

## Do not reproduce

Do not reproduce logos, brand names, proprietary text, real names, email addresses, avatars, photographs, exact file names, code, URLs, financial values, event details, map assets, or specific company/product identities. Ignore global navigation, account widgets, upgrade prompts, referral cards, and unrelated persistent shell panels.

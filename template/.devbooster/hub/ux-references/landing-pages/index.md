# Landing pages

Referências visuais para landing pages completas — páginas de marketing, produto e conversão com múltiplas seções.

Use esta categoria para explorar:
- Estrutura completa de landing page
- Ordem e ritmo das seções
- Hero, features, prova social, CTA
- Diferentes abordagens por segmento (SaaS, ecommerce, fintech, educação)
- Densidade de informação e storytelling visual

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `landing-XX.png` ou `landing-XX.webp` (exemplo: `landing-01.webp`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `header-sections` — seções de cabeçalho e hero
- `feature-sections` — seções de funcionalidades
- `pricing` — seções de preços
- `footer` — rodapés

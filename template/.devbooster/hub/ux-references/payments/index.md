# Páginas de pagamento

Referências visuais para páginas de pagamento, checkout e faturamento — formulários de pagamento, resumo de compra, histórico de transações e billing.

Use esta categoria para explorar:
- Layout de checkout e formulário de pagamento
- Resumo do carrinho ou plano
- Histórico de transações e faturas
- Métodos de pagamento e segurança
- Estados: sucesso, erro, processando

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `payment-XX.png` ou `payment-XX.webp` (exemplo: `payment-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `pricing` — páginas de preços
- `settings` — configurações de conta e cobrança
- `profile` — perfis de usuário

## Overview

A public-facing professional profile for a designer or specialist. The route presents identity, biography, contact information, work history, and selected projects so visitors can evaluate the person and explore their work.

## Route layout blueprint

A wide visual cover leads into a centered identity block with avatar, verification indicator, name, handle, and two actions. Below, the content splits into a broad main column and a narrower contact-information card. The main column continues with biography, a two-column grid of four experience cards, and a projects section with internal category tabs and a two-column project gallery.

## Sections (top to bottom)

- Profile hero: wide cover area, overlapping circular avatar, identity details, and two profile actions.
- About and contact: biography content in the main column, with a compact contact card alongside it containing location and external contact links.
- Experience: four cards arranged in a two-by-two grid, each showing a role, organization, date range, and project action.
- Projects: section heading with category tabs, followed by a two-column gallery of visual project previews.

## Components

- Cover/banner: one wide decorative cover area.
- Identity block: one avatar, verification badge, display name, handle, and two actions.
- About section: one text introduction with a read-more continuation link.
- Contact card: one side card with location, website, portfolio, email, and a copyable profile link.
- Experience cards: four repeated cards in two columns, each with an organization mark, role, company, dates, and a “view project” button.
- Project tabs: one tab row with an all-projects option and three category filters.
- Project gallery: a two-column grid of large visual thumbnails; more content continues below the viewport.

## Density and rhythm

Spacious and editorial, with strong separation between hero, biography, career history, and portfolio content. Repeated cards are compact internally but have generous spacing between sections.

## Observed states

The profile is populated and read-only from the visitor’s perspective. No loading, empty, error, upload, or progress state is visible.

## Observed route interactions

Visible local interactions include profile actions, read-more expansion, contact-link navigation or copying, project-card actions, project category tabs, and overflow menus for profile sections.

## Observed style (qualitative)

Clean, polished, portfolio-oriented, and editorial, combining a strong profile hero with structured professional information.

## Ideal for

Designer portfolios, freelancer profiles, professional directories, creator pages, talent marketplaces, and networking products.

## Do not reproduce

Do not reproduce brands, personal names, handles, proprietary biography text, logos, portraits, cover artwork, project screenshots, or external service icons. Use generic identity content and abstract project placeholders.

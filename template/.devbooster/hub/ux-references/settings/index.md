# Páginas de configurações

Referências visuais para páginas de configurações e preferências — perfil, segurança, equipe, cobrança, notificações e integrações.

Use esta categoria para explorar:
- Navegação entre seções de configurações
- Layout de formulários e toggle switches
- Organização por abas, sidebar ou etapas
- Tipos: perfil, time, billing, notificações, integrações
- Estados: vazio, preenchido, edição

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `settings-XX.png` ou `settings-XX.webp` (exemplo: `settings-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `profile` — páginas de perfil
- `payments` — páginas de pagamento e cobrança
- `dashboards` — dashboards de administração

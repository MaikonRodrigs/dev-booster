## Overview

A security route for changing the account password and reviewing active devices or sessions.

## Route layout blueprint

A profile header and internal tabs sit above a three-field password form. A session section below lists logged-in devices in separate rows.

## Sections (top to bottom)

- password form: current password, new password, confirmation, and minimum-length hint.
- session list: heading, security explanation, overflow action, and two device rows with activity metadata.

## Components

Three masked password inputs, validation hint, two session rows, overflow menu, cancel, and update-password actions.

## Density and rhythm

Balanced, with generous spacing around the form and compact session rows.

## Observed states

Editing state with masked values; one session is active and another is historical.

## Observed route interactions

Tabs, password entry, session menu, cancel, and update password.

## Observed style (qualitative)

Trustworthy, clean, and security-focused.

## Ideal for

Account security and device-session administration.

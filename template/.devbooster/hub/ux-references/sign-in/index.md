# Login (Sign-in)

Referências visuais para páginas de login — autenticação por e-mail/senha, SSO, social login, login sem senha e layouts divididos com prova social ou preview de produto.

Use esta categoria para explorar:

- Formulários centrados e em card
- Layouts divididos (split) com imagem, depoimentos ou proof de produto
- Login por e-mail, social providers e SSO
- Variantes: minimal, editorial, premium, promocional

## Referências

### [login-01](login-01.md) — Login centralizado com troca de conta

- **Tipo:** sign-in page
- **Tags:** `centered` `form` `minimal` `account-switcher`
- **Componentes:** heading, switcher de modo, campos de credenciais, linha utilitária, botões de ação, prompt de rodapé
- **Resumo:** fluxo vertical único com respiro entre grupos. Ideal para SaaS de consumo, apps web leves e entrada convencional.

### [login-02](login-02.md) — Login compacto de credenciais

- **Tipo:** sign-in page
- **Tags:** `compact` `form` `minimal` `efficient`
- **Componentes:** linha de identidade, grupo de credenciais, botões de ação, links secundários
- **Resumo:** muito compacto, com pegada vertical curta. Ideal para rotas simples, diálogos embutidos e layouts estreitos.

### [login-03](login-03.md) — Formulário de login em card com borda

- **Tipo:** card-based sign-in page
- **Tags:** `card` `form` `clean` `structured`
- **Componentes:** heading, card, campos, linha utilitária, ações, prompt de conta
- **Resumo:** card cria agrupamento claro sem seções extras. Ideal para aplicações de negócio e autenticação com limite definido.

### [login-04](login-04.md) — Login alinhado à esquerda em canvas amplo

- **Tipo:** split-canvas sign-in page
- **Tags:** `split-layout` `editorial` `asymmetric` `open`
- **Componentes:** linha de identidade, campos de credenciais, linha utilitária, botões de ação, loader, prompt de conta
- **Resumo:** formulário em coluna estreita com espaço negativo substancial. Ideal para login com cara de landing e desktop-first.

### [login-05](login-05.md) — Login dividido com depoimento

- **Tipo:** split-layout sign-in page
- **Tags:** `split-layout` `testimonial` `trust` `editorial` `polished`
- **Componentes:** painel de depoimento, painel de login
- **Resumo:** duas colunas espaçosas com depoimento proeminente. Ideal para agências, consultorias, criativos e SaaS de alta consideração.

### [login-06](login-06.md) — Login com prova social e carrossel de imagens

- **Tipo:** split-layout sign-in page
- **Tags:** `split-layout` `testimonial` `carousel` `premium` `immersive`
- **Componentes:** formulário de login, módulo de depoimento
- **Resumo:** painel de depoimentos com peso visual substancial. Ideal para produtos de consumo onde confiança e storytelling apoiam o login.

### [login-07](login-07.md) — Login com frame de cabeçalho e opção de SSO

- **Tipo:** sign-in page
- **Tags:** `sso` `enterprise` `product-led` `clean`
- **Componentes:** contexto superior, switcher, campos, controles utilitários, botões, link de SSO
- **Resumo:** frame superior claro com formulário centralizado. Ideal para workspace, B2B SaaS e organizações com SSO.

### [login-08](login-08.md) — Autenticação email-first com múltiplos providers

- **Tipo:** social sign-in page
- **Tags:** `social-login` `email-first` `passwordless` `modern`
- **Componentes:** heading, campo de e-mail, ação primária, divisor, botões de provider, prompt de cadastro
- **Resumo:** segmentação clara entre e-mail e providers. Ideal para progressão sem senha ou login federado.

### [login-09](login-09.md) — Card de login elevado

- **Tipo:** card-based sign-in page
- **Tags:** `card` `minimal` `friendly` `focused`
- **Componentes:** card, campos, controles utilitários, botões de ação, prompt de conta
- **Resumo:** compacto e contido em um card. Ideal para páginas standalone e experiências estilo modal.

### [login-10](login-10.md) — Login ao lado de prova de dashboard

- **Tipo:** split-layout sign-in page
- **Tags:** `split-layout` `product-proof` `analytical` `promotional`
- **Componentes:** formulário de login, depoimento, preview de produto
- **Resumo:** denso no lado da prova e contido no formulário. Ideal para SaaS de dashboard que mostram valor sem interromper o login.

### [login-11](login-11.md) — Login email-first com prioridade Google

- **Tipo:** sign-in page
- **Tags:** `social-login` `email-first` `conversion-oriented` `focused`
- **Componentes:** heading, botão de provider, divisor, campo de e-mail, ação de e-mail, link de SSO
- **Resumo:** muito compacto e de baixo atrito. Ideal para fluxos sem senha ou provider-first.

### [login-12](login-12.md) — Login com depoimento image-led

- **Tipo:** split-layout sign-in page
- **Tags:** `split-layout` `testimonial` `image-led` `editorial` `trust`
- **Componentes:** formulário, painel de prova
- **Resumo:** visual dominante no lado da prova. Ideal para produtos de marca, agências e serviços onde depoimentos apoiam conversão.

### [login-13](login-13.md) — Login dividido com arte abstrata

- **Tipo:** split-layout sign-in page
- **Tags:** `split-layout` `minimal` `artistic` `brand-forward`
- **Componentes:** formulário, visual
- **Resumo:** coluna funcional simples contra coluna visual imersiva. Ideal para software criativo, portfólios e identidade visual sem prova.

### [login-14](login-14.md) — Login com depoimento de retrato e card overlay

- **Tipo:** split-layout sign-in page
- **Tags:** `split-layout` `testimonial` `overlay-card` `warm` `editorial`
- **Componentes:** formulário, card de depoimento
- **Resumo:** âncora visual forte com card overlay sobre a imagem. Ideal para agências criativas, serviços e produtos high-touch.

### [login-15](login-15.md) — Login com promoção de dashboard em carrossel

- **Tipo:** split-layout sign-in page
- **Tags:** `split-layout` `product-proof` `carousel` `promotional` `energetic`
- **Componentes:** formulário de login, preview de produto, controles de carrossel
- **Resumo:** lado promocional denso na parte superior-média. Ideal para onboarding de produtos, dashboards e descoberta de produto.

### [login-16](login-16.md) — Login centralizado com marca decorativa de acesso

- **Tipo:** sign-in page
- **Tags:** `centered` `illustrated` `friendly` `minimal`
- **Componentes:** ilustração, heading, campos, linha utilitária, botões de ação, prompt de conta
- **Resumo:** centralizado com lacuna entre elemento decorativo e formulário. Ideal para login de consumo com ilustração contextual.

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `login-XX.png` ou `login-XX.webp` (exemplo: `login-01.png`). Após salvar, atualize o mapa de tags e o catálogo de referências deste `index.md` (formato no `VISION_PROMPT.md`).

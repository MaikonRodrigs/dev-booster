# Páginas de cadastro

Referências visuais para páginas de criação de conta — formulários de registro, onboarding inicial e ativação.

Use esta categoria para explorar:
- Formulário de cadastro completo
- Etapas de registro (passo a passo)
- Autenticação social no cadastro
- Layout dividido com imagem ou ilustração
- Integração com termos e políticas

## Como adicionar referências

Salve as imagens nesta pasta seguindo o padrão `signup-XX.png` ou `signup-XX.webp` (exemplo: `signup-01.png`). Opcionalmente, use este `index.md` para catalogar cada referência com nome e descrição.

## Categorias relacionadas

- `sign-in` — páginas de login
- `verification` — páginas de verificação
- `forgot-password` — recuperação de senha

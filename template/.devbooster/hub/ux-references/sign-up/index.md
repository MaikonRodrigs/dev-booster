# Cadastro (Sign-up)

Referências visuais para páginas de cadastro — criação de conta, fluxos em múltiplas etapas, social login, trial e layouts divididos com preview de produto ou depoimentos.

Use esta categoria para explorar:

- Formulários centrados e em card
- Layouts divididos (split) com preview de produto, imagem ou depoimentos
- Fluxos em múltiplas etapas (password step, progress)
- Social login e cadastro email-first
- Variantes: minimal, editorial, premium, promocional

## Referências

### [signup-01](signup-01.md) — Formulário centralizado de criação de conta

- **Tipo:** sign-up page
- **Tags:** `centered` `form` `minimal` `conversion-oriented`
- **Componentes:** controle segmentado com dois modos de auth, inputs nome/e-mail, input de senha com toggle de visibilidade, lista de requisitos de senha, botão submit + social, link de login
- **Resumo:** compacto e equilibrado, com separação clara entre grupos. Ideal para trials de SaaS, produtividade, dev tools e registro de baixo atrito.

### [signup-02](signup-02.md) — Cadastro com troca local de conta

- **Tipo:** sign-up page
- **Tags:** `centered` `form` `clean` `enterprise`
- **Componentes:** controle segmentado de dois modos, inputs nome/e-mail, senha com visibilidade, regra inline de tamanho mínimo, botões primário/secundário, ação de SSO enterprise
- **Resumo:** esparso e focado. Ideal para onboarding de SaaS de negócio com autenticação enterprise opcional.

### [signup-03](signup-03.md) — Etapa de criação de senha com progresso

- **Tipo:** multi-step sign-up flow
- **Tags:** `multi-step` `password` `minimal` `guided`
- **Componentes:** dois inputs de senha com visibilidade, botão continuar, stepper de quatro etapas
- **Resumo:** muito espaçoso, enfatizando uma única tarefa. Ideal para onboarding progressivo com etapas focadas.

### [signup-04](signup-04.md) — Cadastro dividido com preview de produto

- **Tipo:** split-layout sign-up page
- **Tags:** `split-layout` `product-preview` `editorial` `product-led`
- **Componentes:** formulário de três campos, guia de senha com visibilidade, ações primária/social/login, ilustração não funcional de dashboard
- **Resumo:** formulário compacto com preview amplo do produto. Ideal para analytics, colaboração e SaaS onde mostrar o produto converte.

### [signup-05](signup-05.md) — Cadastro dividido com painel visual abstrato

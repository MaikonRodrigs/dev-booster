# Reference — Sign-up form with local account switch

- image: signup-02.png
- type: sign-up page
- source: vision description (image not stored)

## Overview

A registration route combining a compact form with a direct way to switch to login, aimed at a free-trial entry point.

## Route layout blueprint

A narrow centered column contains a heading and subtitle, a two-option auth switch, name/email/password fields, one visible password rule, a primary action, a social sign-up button, and an enterprise authentication link.

## Sections (top to bottom)

- Intro: registration title and trial message.
- Auth switch: sign-up selected beside log-in.
- Form: three vertically stacked fields.
- Actions: password guidance, primary button, social button, and SSO link.

## Components

- Two-mode segmented control.
- Name and email inputs.
- Password input with visibility control.
- Inline minimum-length rule.
- Primary and secondary registration buttons.
- Enterprise SSO text action.

## Density and rhythm

Sparse and focused, with generous unused space around the compact form.

## Observed states

Empty registration form; no error or loading state.

## Observed route interactions

Auth switch, password toggle, submit, social sign-up, SSO, and login path appear interactive.

## Observed style (qualitative)

Clean, restrained, and centered.

## Ideal for

Business SaaS onboarding with optional enterprise authentication.

## Do not reproduce

Ignore global brand marks, provider logos, product names, and proprietary text. The image is not stored.

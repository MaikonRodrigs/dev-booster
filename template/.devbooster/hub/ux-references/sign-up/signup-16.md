# Reference — Compact trial sign-up card

- image: signup-16.png
- type: card-based sign-up page
- source: vision description (image not stored)

## Overview

A compact trial-registration card optimized for fast completion in a small visual footprint.

## Route layout blueprint

A centered raised card contains a small product mark area, trial title, supporting subtitle, three stacked fields, a password requirement, primary submit, social sign-up, and an existing-account link.

## Sections (top to bottom)

- Card intro: trial title and short completion message.
- Credentials: name, email, and password fields.
- Validation and actions: one password rule, primary button, social button, and login link.

## Components

- Card container.
- Name and email inputs.
- Password input with visibility toggle.
- Inline password rule.
- Primary and social buttons.
- Login link.

## Density and rhythm

Compact, efficient, and evenly stacked.

## Observed states

Empty form; no error, loading, or progress state.

## Observed route interactions

Fields, password visibility, buttons, and login link appear interactive.

## Observed style (qualitative)

Friendly, contained, and conversion-oriented.

## Ideal for

Trial sign-up modals, embedded onboarding, and compact authentication pages.

## Do not reproduce

Ignore product marks, provider branding, proprietary text, and exact visual styling.
